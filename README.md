## 📌 Project Overview

The **Swiggy Sales Analysis Dashboard** is an interactive data visualization project developed using Microsoft Power BI. It focuses on analyzing food delivery and restaurant-related data to understand pricing, discounts, customer ratings, and other key business metrics.

The dashboard transforms raw data into meaningful insights through interactive visualizations, KPI cards, and charts to support data-driven business decisions.

## 🎯 Project Objectives

- Analyze average product MRP and selling prices.
- Evaluate discount percentages across products.
- Understand customer ratings and rating distribution.
- Track total ratings to measure customer engagement.
- Present key performance indicators through an interactive dashboard.
- Identify patterns and trends to support business analysis.

## 🛠️ Tools & Technologies

- **Power BI** – Interactive dashboard and data visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – Calculated measures and KPIs
- **Microsoft Excel / CSV** – Data preparation, if applicable

## 📊 Key Performance Indicators (KPIs)

| KPI | Description |
|---|---|
| Average Price MRP | Average maximum retail price of products |
| Average Discount % | Average discount offered on products |
| Average Price | Average selling price |
| Average Ratings | Average customer rating |
| Total Ratings | Total number of customer ratings |

## 🔍 Analysis & Insights

This project helps explore questions such as:

## ⚙️ Project Workflow

1. Import the dataset into Power BI.
2. Clean and transform the data using Power Query.
3. Create calculated measures using DAX.
4. Design KPI cards and interactive visualizations.
5. Analyze the results and identify useful business insights.

## 🚀 How to Use This Project

1. Clone or download this repository.
2. Install [Microsoft Power BI Desktop](https://www.microsoft.com/power-platform/products/power-bi/desktop).
3. Open the `.pbix` file in Power BI Desktop.
4. Refresh the data if the source dataset is available.
5. Explore the dashboard and interact with the visualizations.
